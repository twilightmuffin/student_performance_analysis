# student_performance_analysis
An Excel-based data analytics project that examines factors that may contribute to student academic performance by gender using PivotTables and data visualizations.

Dataset: Cortez, P. (2008). Student Performance. UCI Machine Learning Repository. https://doi.org/10.24432/C5TG7T
License: https://creativecommons.org/licenses/by/4.0/
Analysis and Excel workbook modifications by the repository author.
